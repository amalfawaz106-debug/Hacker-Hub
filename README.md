CyberGuard Security Tool(JAVA)
Cyber Guard is a simple java security tool that help users analyze potential cybersecurity risks ; It provides these 3 features:
1>>PASSWORD STRENGTH CHECKER
when we add a password it will be evaluated according to:
.Minimum length greater than 8
.contain at least 1 capital letter
.contain at least 1 smaller letter
.contain at least 1 number and 1 special characters
RETURNS:
<Weak, Medium , Strong>

2>>PHISHING DETECTOR
when we add an email it will be evaluated according to:
.Urgent language (e.g., "urgent")
.Suspicious phrases (e.g., "click here")
.Requests for verification or passwords
.Offers that seem too good to be true (e.g., "free", "won")
RETURNS:
<Likely Safe , Suspicious , High risk phishing>

3>>URL DETECTOR
.when we add url it will be evaluated according to:
.Suspicious keywords (login, verify, secure, account)
.Long URLs
.Excessive number of "/" characters
.Use of IP address instead of domain
RETURNS:
<Likely Safe , Suspicious , High risk phishing>
